# P2 求解四次方程组

- 试卷：2023 计算机转专业机试（大二）
- 平台题号：10
- 分值：100
- 难度：待定
- 主要考点：—

---

## 题目描述

给定四次方程 $x^4+ax^3+bx^2+cx+d=0$，以及四个按从左到右排列、两两不相交的闭区间 $[L_i,R_i]$。

保证每个区间内恰好存在一个实数根，且区间两端的函数值严格异号。请按从小到大的顺序输出这四个根。

## 输入格式

第一行四个实数 `a b c d`。

接下来四行，每行两个实数 `L R`，表示一个根所在的区间。

## 输出格式

一行输出四个实数，均保留 6 位小数，使用空格分隔。

## 数据范围

系数和区间端点的绝对值不超过 $10^6$；保证题述条件成立。评测采用绝对误差不超过 $5\times10^{-6}$ 的浮点容差比较。

## 样例输入

```text
0 -5 0 4
-3 -1.5
-1.5 -0.5
0.5 1.5
1.5 3
```

## 样例输出

```text
-2.000000 -1.000000 1.000000 2.000000
```
