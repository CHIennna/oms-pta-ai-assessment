## 题目描述

王子需要在若干个房间中确定公主所在的房间。每个房间恰好住着一个人，所有人都知道每个人所在的房间。

参与者分为三类：支持王子与公主婚姻的人始终说真话；反对婚姻的人始终说假话；中立者可以任意说真话或假话。公主属于第一类。

王子可以向任意参与者询问下列三类问题中的任意一种：

1. 你是谁？
2. 某个指定房间里是谁？
3. 公主在哪个房间？

已知三类人的数量分别为 `a,b,c`。请判断王子是否能够在任何情况下都确定公主所在的房间。若可以，请求出最坏情况下保证确定公主位置所需询问的最少问题数。

## 输入格式

输入一行三个整数：

```text
a b c
```

分别表示始终说真话、始终说假话和回答任意的参与者数量。

## 输出格式

如果无法保证确定公主的位置，输出：

```text
NO
```

如果可以确定，第一行输出 `YES`，第二行输出最坏情况下所需的最少问题数。

## 数据范围

```text
1<=a<=200000
0<=b,c<=200000
```

## 样例输入 1

```text
2 0 0
```

## 样例输出 1

```text
YES
1
```

## 样例输入 2

```text
1 1 0
```

## 样例输出 2

```text
NO
```
