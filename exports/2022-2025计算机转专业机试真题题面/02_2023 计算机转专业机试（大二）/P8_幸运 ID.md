# P8 幸运 ID

- 试卷：2023 计算机转专业机试（大二）
- 平台题号：16
- 分值：100
- 难度：待定
- 主要考点：—

---

## 题目描述

给定一个长度为 6 的数字字符串作为票据 ID。

如果前三位数字之和等于后三位数字之和，则称该 ID 为幸运 ID。

一次操作可以选择 ID 中任意一位数字，并将其替换为 `0~9` 中的任意数字。请计算至少需要进行多少次操作，才能将给定 ID 变成幸运 ID。

## 输入格式

输入一行长度为 6 的字符串，仅包含数字 `0~9`。

## 输出格式

输出一个整数，表示最少操作次数。

## 样例输入 1

```text
000000
```

## 样例输出 1

```text
0
```

## 样例输入 2

```text
000018
```

## 样例输出 2

```text
1
```
