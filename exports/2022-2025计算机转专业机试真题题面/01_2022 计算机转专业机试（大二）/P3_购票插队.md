## 题目描述

共有 `n` 个人依次来到售票队伍。每个人的编号按照到达顺序依次为 `1~n`。

系统维护一个总怒气值，初始为 `0`。给定怒气阈值 `m`。

每个人有两种行为：

### 正常排队

输入：

```text
0
```

表示该人正常排到当前队伍末尾。

### 插队

输入：

```text
1 x y
```

表示该人插到当前队伍中编号为 `x` 的人前面。

本次插队会使原本从 `x` 开始到队尾的每个人增加 `y` 点怒气，因此总怒气值增加：

```text
受影响人数 × y
```

如果一次插队后总怒气值严格大于 `m`，则立即将当前队伍中所有插队者赶走，只保留此前正常排队的人，并将总怒气值清零。

题目保证执行插队操作时，编号 `x` 的人当前仍在队伍中。

请输出所有 `n` 个人处理完毕后的最终队伍以及当前总怒气值。

## 输入格式

第一行输入两个整数：

```text
n m
```

接下来 `n` 行依次描述编号为 `1~n` 的人的行为。

若该人正常排队，输入：

```text
0
```

若该人插队，输入：

```text
1 x y
```

## 输出格式

第一行按照从队首到队尾的顺序输出最终仍在队伍中的人员编号，编号之间用一个空格分隔。

第二行输出当前总怒气值。

## 样例输入

```text
5 5
0
0
1 1 3
0
0
```

## 样例输出

```text
1 2 4 5
0
```
