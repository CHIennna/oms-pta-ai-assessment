# P5 淹没岛屿

## 题目描述

给定一张 `N×N` 的海域地图，其中字符 `.` 表示海水，字符 `#` 表示陆地。

上下左右四个方向相邻的陆地格属于同一座岛屿。

由于海平面上升，所有与海水上下左右相邻的陆地格都会被淹没。请计算有多少座岛屿会因此被完全淹没。

## 输入格式

第一行输入一个整数 `N`。

接下来 `N` 行，每行输入一个长度为 `N` 的字符串，表示海域地图。

保证地图的第 1 行、第 1 列、第 `N` 行和第 `N` 列均为海水。

## 输出格式

输出一个整数，表示会被完全淹没的岛屿数量。

## 数据范围

```text
1<=N<=1000
```

## 输入样例

```text
7
.......
.##....
.##....
....##.
..####.
...###.
.......
```

## 输出样例

```text
1
```
