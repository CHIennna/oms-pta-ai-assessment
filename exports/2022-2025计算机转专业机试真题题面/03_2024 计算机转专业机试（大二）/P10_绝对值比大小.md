# P10 绝对值比大小

- 试卷：2024 计算机转专业机试（大二）
- 平台题号：26
- 分值：100
- 难度：待定
- 主要考点：—

---

## 题目描述

给定 `n` 个整数，请按照以下规则进行排序：

1. 绝对值较大的数排在前面；
2. 如果两个数的绝对值相同，则原值较小的数排在前面。

输出排序后的序列。

## 输入格式

第一行输入一个整数 `n`。

第二行输入 `n` 个整数。

## 输出格式

在一行中输出排序后的 `n` 个整数，整数之间使用一个空格分隔。

## 输入样例

```text
3
3 -4 2
```

## 输出样例

```text
-4 3 2
```
