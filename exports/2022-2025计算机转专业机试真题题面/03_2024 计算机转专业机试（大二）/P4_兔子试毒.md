- 难度：普及

## 题目描述

某实验室有 1000 瓶外观完全相同的药水，其中**恰好一瓶含有剧毒**，其余药水均无毒。兔子只要喝下一滴有毒药水，就会在 24 小时后死亡；如果没有喝到毒药，则不会死亡。实验人员可以让一只兔子饮用多瓶药水，也可以让多只兔子饮用同一瓶药水。

最初，实验人员希望在**一天内**准确找出 1000 瓶药水中唯一的毒药，并尽量减少兔子的数量。后来，他们将问题推广：给定 `N` 瓶药水，编号从 `1` 到 `N`，最多允许进行 `D` 天实验，每天开始时可以让仍然存活的兔子饮用若干瓶药水，并在当天结束时观察它们的生死情况。实验可以根据此前的观察结果安排后续试验。

对于一只兔子，实验结束时会留下一个整数记录：

- `0` 表示它在整个实验期间存活；
- `d`（`1 ≤ d ≤ D`）表示它在第 `d` 天结束时死亡。

实验室选择能够**保证区分全部 N 瓶药水**的最少兔子数 `K`，并约定使用如下统一记录规则，以便仅凭观察结果还原药水编号。

把一份完整的实验记录看成依次对应**兔子 1、兔子 2、……、兔子 K**的 `K` 个整数。比较两份不同记录时，从**兔子 K**开始，再依次比较兔子 `K-1`、……、兔子 `1`；在第一个不同的位置，数值较小的记录排在前面。

在这一排序规则下，实验室将所有可能的完整记录按顺序排列，并依次将**最前面的 N 份记录**对应到编号为 `1` 至 `N` 的药水。实验人员按照这套约定安排试验，保证每瓶药水的真实毒性都能产生其对应的记录。

现在给出实验结束后的记录。请输出实验所需的最少兔子数 `K`，以及唯一有毒的药水编号 `X`。

## 输入格式

第一行输入一个整数 `T`，表示实验组数。

每组实验首先输入两个整数 `N D`。

随后输入 `K` 个整数，依次表示兔子 `1` 至兔子 `K` 的观察结果。**输入中不单独提供 K**，需要根据 `N` 和 `D` 确定本组记录的长度。

特别地，若 `N=1`，则不需要兔子，本组没有观察结果。

各个整数之间以空白字符分隔，不保证兔子记录独占一行。

## 输出格式

对于每组实验，输出一行两个整数 `K X`，其中 `K` 是实验所需的最少兔子数，`X` 是唯一有毒的药水编号。

## 输入样例

```text
3
1000 1
1 0 1 1 0 1 0 1 0 1
1000 2
1 1 1 0 0 2 0
1 5
```

## 输出样例

```text
10 686
7 500
0 1
```

## 数据范围与约定

- `1 ≤ T ≤ 5000`。
- `1 ≤ N ≤ 10^18`。
- `1 ≤ D ≤ 10^9`。
- 全部实验组所需兔子数之和不超过 `2 × 10^5`。
- 保证全部观察记录合法，并与某一瓶药水唯一对应。
- 当 `N=1` 时，最少兔子数为 `0`，即空记录也参与上述规则。
