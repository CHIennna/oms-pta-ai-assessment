## 题目描述

给定一个 `R×C` 的迷宫。

每个格子可以向上、下、左、右相邻格移动，但相邻格之间可能存在墙壁。

可以从第一行任意一个格子作为起点。当到达最后一行任意一个格子时，视为成功走出迷宫。每移动到一个上下左右相邻且中间没有墙壁的格子，记作 1 步。

请判断能否走出迷宫；如果可以，输出最少步数。

### 墙壁输入

在 `R,C` 之后共有 `2R-1` 行墙壁信息。

从第 1 行墙壁信息开始编号：

- 第 `2r-1` 行有 `C-1` 个整数，第 `j` 个数表示 `(r,j)` 与 `(r,j+1)` 之间是否有墙；
- 第 `2r` 行有 `C` 个整数，第 `j` 个数表示 `(r,j)` 与 `(r+1,j)` 之间是否有墙。

其中：

```text
1 表示有墙
0 表示没有墙
```

## 输入格式

第一行输入两个整数 `R,C`。

接下来输入 `2R-1` 行墙壁信息。

## 输出格式

如果可以到达最后一行，输出最少移动步数。

否则输出：

```text
No Way
```

## 数据范围

```text
1<=R,C<=1000
```

## 样例输入

```text
2 2
0
0 0
0
```

## 样例输出

```text
1
```
