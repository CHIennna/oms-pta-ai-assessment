# 运行与评测

## 职责

接收代码运行或提交请求，使用受限本地进程编译执行，按正式测试点评分并返回判定结果。

## 代码位置

- `src/client/judge/judge-machine.js`：浏览器端请求、状态和结果展示。
- `src/client/judge/judge-score.js`：客户端与服务端共用的分数计算规则。
- `src/server/judge/local-judge.js`：编译器、资源限制、普通输出比较和特殊判题器。
- `server.js`：`/api/judge`、限流、试卷身份验证、测试点注入和成绩保存。
- 根目录四个测试 ZIP：正式输入输出数据。

## 安全边界

正式测试点只在服务端读取。提交请求中的自带测试数据不能替代服务器测试库。公网环境必须使用容器级隔离；Windows 本地模式仅适合受控环境。

## 验证

运行 `npm test`；再手动验证编译错误、答案错误、超时、正确答案和考试结束后的拒绝提示。不得删除或移走测试 ZIP，除非同时迁移所有 `testArchive.file` 配置。
