# 登录与个人资料

## 职责

提供注册、登录、退出、会话检查、个人资料修改、密码修改、CSRF 校验和登录限流。

## 代码位置

- `src/server/auth/auth.js`：服务端账号、会话、密码哈希和接口处理。
- `src/client/core/pta-clone.js`：登录弹窗、请求封装和登录状态。
- `src/client/core/pta-clone-interactions.js`：账号菜单和个人资料表单。
- `auth.test.js`：账号与界面回归测试。

## 数据与安全

账号数据写入服务端数据目录，不进入题库文件。浏览器修改请求必须带同源标识与 CSRF 值；修改密码后旧会话失效。文档、日志和测试夹具不得保存真实密码或完整学生身份信息。

## 验证

运行账号测试，并手动检查注册、错误密码、退出、刷新恢复会话、修改昵称和修改密码。
